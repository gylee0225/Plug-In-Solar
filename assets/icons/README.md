# Plug-In Solar icons
Original editable SVG icons on a 24 × 24 grid. Deep teal and solar amber for light UI; pale teal and amber for dark UI. `.dark.svg` files are the dark variants.
PNG exports at 24 and 48 pixels are included for user-object workflows. Use SVG files for Rhino Script Editor component/project icons. `preview.png` displays the complete family.
